# Каталог установленной игры

Каталог рассчитан на **Steam build 24656030**. Строка публичной версии игры не
устанавливалась; каталог не объявляет себя актуальным для любой новой сборки.

Офлайн-регенерация из сохранённых источников:

```powershell
node scripts/import-game-data.mjs
node node_modules/vitest/vitest.mjs run tests/catalog.test.ts
```

Восстановление игровых иконок из закреплённого upstream требует сети:

```powershell
node scripts/import-game-data.mjs --download-icons
```

Нормализованный файл нельзя править вручную. Исходные данные лежат в `source/`,
ручные сопоставления стабильных ID и тематических групп — в `overrides.json`.
Импорт проверяет SHA256 исходных файлов; загрузка иконок — Git blob SHA.
При обновлении игры сначала сохранить новые исходники и происхождение, затем
просмотреть diff, назначить ID добавленным предметам/рецептам и повторить проверки.

## Проверка и ограничения

- Импортируются 276 производственных рецептов, включая 110 альтернативных;
  152 предмета, 11 производственных зданий, утилизатор, пять добытчиков.
- 872 FGRecipe из дампа полностью распределены на импортированные и исключённые
  с причиной. Строительство, ручные/неподдержанные здания и сезонные рецепты
  доступны для аудита в `audit-report.json`, но не входят в модель фабрики.
- Количества жидкостей и газов делятся на 1000: литры дампа → м³. В каталоге
  сохраняются количества за цикл и длительность, а не округлённые потоки.
- 270 производственных рецептов upstream сопоставлены; два виртуальных
  реакторных цикла исключены. В игре добавлены шесть рецептов; три рецепта
  отличаются количествами/временем от upstream. Все расхождения записаны.
- Средняя мощность ускорителя подтверждена описанием продукта в самом дампе;
  конвертер 250 МВт и квантовый кодировщик 1000 МВт дополнительно сверены с
  Official Satisfactory Wiki. Пиковая мощность каждого рецепта задаётся отдельно.
  Сама кривая UCurveFloat из установленной игры не извлечена.
- Русские названия взяты из `ru.json`. Тематические группы заданы вручную:
  точное совпадение с группами и порядком меню игры **не проверено**.
  Поэтому общий `provenance.verified` остаётся `false`, несмотря на сверенные поля.
  Исследование официальных Headers установило причину: Docs не экспортирует
  `mCategory`, `mOverriddenCategory` и классы `FGItemCategory` с заголовками/порядком.
  `mSubCategories` в заголовке относится к меню строительства зданий.
  При этом **внутри групп применён игровой `mManufacturingMenuPriority`** для всех
  276 рецептов; при равенстве используется русский алфавит, без аттестации в игре.
  Подробности и недостающие сведения перечислены в `source/menu-evidence.json`.
- Скважины с общим компенсатором давления не представлены независимыми узлами.
  Азот можно задать внешним потоком; энергия его получения остаётся за границей.
- Утилизация доступна только твёрдым предметам с положительными игровыми
  `mResourceSinkPoints`; жидкости и радиоактивные отходы не исчезают.
- 162 исходные иконки занимают около 3,35 МБ. У биохимического скульптора
  и утилизатора нет иконки в закреплённом upstream; UI использует свой fallback.
