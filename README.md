# another-satisfactory-calculator

Персональный русскоязычный калькулятор Satisfactory. React/Vite frontend,
HiGHS в Web Worker и Fastify/SQLite для аккаунтов, миров и фабрик.

## Запуск

Нужны Node.js 24+ и pnpm. Из корня проекта:

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

Frontend: http://127.0.0.1:5173, API: http://127.0.0.1:3001.
Для уже установленного проекта без package manager: `node scripts/dev.mjs`.

Готовая сборка:

```powershell
pnpm build
pnpm start
```

Сервер раздаёт frontend и API на порту 3001. Порт меняется через `PORT`,
файл базы — через `DATABASE_PATH`; по умолчанию `.data/users.sqlite`.
Настройки cookies и API описаны в [apps/api/README.md](apps/api/README.md).

## Возможности

- Максимум выпуска или заданный заказ. Для нескольких продуктов — пропорции,
  приоритеты либо веса; у каждого продукта можно задать минимум и максимум.
- Ограничения источников, месторождений, транспорта, средней и максимальной
  мощности с резервом; предел физического количества зданий каждого типа.
- Цели «энергия», «условная стоимость сырья», «меньше зданий» и сравнение
  вариантов при одинаковом заказе. Альтернативы сравниваются по всей цепочке.
- Повторный расчёт проверяет пользу конкретного источника, увеличения мощности,
  открытия рецепта/здания или утилизации, в том числе совместных изменений.
- Каталог с поиском «производит / использует / везде», сворачиваемыми группами,
  величинами за цикл, в минуту и на единицу выбранного выхода.
- «Построить»: число машин, заданная частота, активные и средние потоки,
  мощность, материалы зданий, копирование чисел и локальные отметки строительства.
- Мир хранит прогресс HUB/MAM и ручные открытия; несколько фабрик наследуют его
  через снимки. Изменения прогресса сначала показываются для просмотра.
- Справочник MAM и фаз HUB показывает связанные исследования для закрытого
  рецепта, варианты ИЛИ и неизвестные связи; завершение отмечается вручную.
- Справочник MAM и фаз HUB показывает связанные исследования для закрытого
  рецепта, варианты ИЛИ и неизвестные связи; завершение отмечается вручную.
- Гостевые черновики, JSON, аккаунты и сохранённые профили остаются доступны.
  Фабрики сохраняются явно в разделе «Миры и фабрики»; импорт пространства добавляет
  копии с новыми ID. Старые планы V1 читаются без изменения их исходного смысла.

## Возможности P2

- Расширение существующего производства: закреплённые и свободные линии,
  сравнение «оставить / добавить / перестроить», отдельная ведомость новых зданий.
- Партии для лифта/склада: количество, запас, срок и расчёт нужного выпуска.
- Конечный бюджет Somersloops и скважины с общим компенсатором;
  материалы компенсатора и всех настроенных спутников включены в ведомость.
- Заметки и резерв источников, явная стоимость энергии импорта, отгрузки побочных
  продуктов. Общие узлы мира распределяются между фабриками конечными квотами.

## Границы расчёта

Частоты заданы пользователем. Средние потоки моделируют долю времени работы;
75% времени работы при 100% частоте не заменяется частотой 75%. Пиковая оценка
консервативна, накопители, фазы циклов, standby и запуск не моделируются.
Положительные границы продуктов и заданный выпуск поддерживаются от 0,000001
в минуту; меньший масштаб отклоняется с объяснением. При численном сбое
физических количеств выводится ошибка, а не ложное утверждение о невыполнимости.
Неизвестная энергия внешних поставок исключена; явно заданная стоимость учтена.
Автоподбор частот и динамика запуска остаются вне модели. Названия и состав
категорий подтверждены игровыми assets; порядок категорий с отсутствующим
приоритетом и равными приоритетами дополняется русским алфавитом.
Плавильня поддерживает один усилитель по общим настройкам игровой подсистемы.
Квоты разных черновиков проверяются
совместно при сохранении пространства. Партия оценивает время после выхода на режим.

Статус проверок и ограничений: [docs/STATUS.md](docs/STATUS.md).

[packages/game-data/README.md](packages/game-data/README.md).

## Проверки

```powershell
pnpm test
pnpm typecheck
pnpm build
pnpm test:ui
```

Для UI предварительно запустите приложение. По умолчанию тесты используют
порт 5173 и установленный Chrome. Для готовой сборки задайте
`$env:PLAYWRIGHT_BASE_URL='http://127.0.0.1:3001'` перед `pnpm test:ui`.
Браузерные тесты создают технические аккаунты; проверочную базу можно отделить
через `DATABASE_PATH` при запуске сервера. Скриншоты и traces лежат в `output/`.

Правила разработки: [AGENTS.md](AGENTS.md). Данные игры и сторонний код:
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
