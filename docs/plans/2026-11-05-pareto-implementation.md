# Реализация обзора Парето и самообеспечения

> Исполнение: superpowers:executing-plans, непрерывно в текущем сеансе.

**Цель:** реализовать согласованный обзор и энергетические цепочки.
**Архитектура:** дополнительные настройки smooth-power; генераторные режимы как
проверенные материальные рецепты с отдельной выработкой; последовательные решения
с ограничениями отдельных потоков. React/worker, TypeScript, HiGHS, Fastify/SQLite.
**Спецификация:** [согласована 2026-11-05](2026-11-04-pareto-factories-design.md).

## Ограничения

Фиксированный выпуск, ≤12 точек за проход, 60 секунд, частичные результаты.
Никаких весов редкости, предварительной минимизации машин и скрытых миграций.
Самообеспечение из первичного сырья; генераторы 100%, покрытие пика с резервом.

## Проверки риска

Несколько источников одного предмета; внешняя энергия против локальной сети;
нулевые лимиты; устаревшие сообщения worker; отсутствие открытия генератора в мире.
Каждый случай проверяется в задаче, владеющей соответствующим поведением.

## Журнал

- Начальная рабочая копия: наши STATUS/спецификация и чужой CLAUDE.local.md.
- Решение: исполнять без нового согласования плана — пользователь явно потребовал
  реализацию. Документы в docs/plans, поскольку docs/superpowers игнорируется Git.
- Контракты между задачами: Recipe.generation описывает выработку и семейство;
  Result.generation описывает проверенную сводку; Settings.pareto выбирает стратегию.
  Source.limit остаётся индивидуальным, Settings.inputLimits ограничивает сумму.
- Коммиты/публикация не входят в результат этой задачи; проверки ведутся по diff.

- Задачи 1–3: тесты нового расчёта и генерации сначала выявляли отсутствие
  функций/каталога, затем прошли. 257 Vitest, TypeScript и production build PASS.
- Финальный reviewer: два замечания — происхождение топлива и полнота сравнения.
  Преобразование железа в уголь воспроизведено отдельным тестом (RED), затем
  устранено сертификатом потока (GREEN). Добавлена независимая проверка подделки.
  Сравнение включает ресурсы базы, разницу машин и добавленные/удалённые рецепты.
- Решение: подтвердить происхождение подмножеством реальных потоков, не запрещать
  преобразования для остальной продукции. Стоимость — дополнительные LP-переменные.
- Отдельная проверка продолжения выявила возможность передать другой Plan в чистую
  функцию solvePareto; добавлена проверка снимка, регрессионный тест RED → GREEN.
- Reviewer не проверял браузер, весь импорт и все коэффициенты. Исполнитель проверил
  импорт повторным запуском с SHA-256, базовые семейства ручными примерами и UI.
  Глобальная полнота фронта не заявляется, как и в согласованной спецификации.

- Интеграция завершена: 23 уникальных UI-сценария (7/7 и 17/18, исправленный
  legacy target сценарий повторно 1/1). Desktop/390px осмотрены. Полный UI-набор
  и Docker не запускались. Пользовательская база не менялась.
