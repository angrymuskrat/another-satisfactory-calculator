# План реализации схем строительства

Дата: 2026-09-07. Первые два вида прямо запрошены к реализации.

**Цель:** показать рассчитанную цепочку по уникальным типам и по отдельным машинам.
**Архитектура:** независимая производная модель из ConstructionModel и назначений
Result; React-карточки и SVG-связи; общие предметные потоки вместо выдуманной
попарной маршрутизации. Solver и API сохраняются.
**Стек:** TypeScript, React, SVG, Vitest, Playwright; Node.js 24+.
**Спецификация:** [поведение и будущая плоская схема](../construction-schematics.md).
Исполнение последовательно в текущей задаче; итоговый независимый обзор —
по навыку requesting-code-review. Не коммитить посторонние изменения.

## Обязательные условия

Русский UI; Sankey не использовать. Частота, доля работы, средняя и пиковая
мощность различаются. Все потоки имеют назначения, количество машин и энергия
не меняются при переключении вида. Устаревшие результаты не показывать как текущие.

## Дальнейшая реализация

Подробная плоская схема развивается по пяти шагам спецификации: проверенные
данные портов → конкретная топология → 2D-раскладка → ведомость/экспорт →
версионированное сохранение. Длины, напор, пуски и география мира не выводятся
из текущей стационарной модели и требуют самостоятельных данных/постановки.
