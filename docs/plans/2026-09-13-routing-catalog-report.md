# Отчёт: интерфейс справочника распределений

Дата: 2026-09-13. Выполнена часть задачи 4 — самостоятельный справочник.
Интеграция найденной разводки в результат оптимизатора и схему фабрики
принадлежит основной задаче и этим отчётом не подтверждается.

## Реализовано

- Пункт меню «Схемы разделителей», заголовок и описание в `App.tsx`.
- `SplitterSchemes.tsx`: фильтры максимальной глубины 1–4, числа выходов,
  отдельной точной дроби и полного вектора пропорций. Пропорции сравниваются
  независимо от общего множителя и порядка, посредством целочисленных
  перекрёстных произведений. Формат ввода пояснён в интерфейсе.
- Полный набор выходов в дробях и процентах, фактическая глубина, количество
  разделителей и соединителей, проверенный граф и доступный текст всех связей.
  Параллельные физические ветви имеют отдельные линии. Фильтр малых потоков
  не применяется. Геометрия — обычный граф с одинаковой толщиной связей.
- Пробный вход и пропускная способность: пересчитываются подписи конечных
  выходов и всех связей, перегрузка проверяется для каждого ребра, включая
  входную ленту. Эти значения локальны для справочника.
- Worker `splitterCatalog.worker.ts` использует `DistributionSearch` и проверяет
  каждую выдаваемую конструкцию через `validateDistribution`. Одна порция:
  максимум 1000 начатых состояний, 200 результатов, 200 мс поиска. Валидация
  и отправка результатов выполняются после ограниченного поиска.
- Следующие порции запрашиваются кнопкой, список отображается страницами по
  25 распределений. Нет непрерывного автоматического перебора глубины 4.
  Показываются число полученных распределений, число обнаруженных состояний
  и состояние полноты. Фильтры применяются только к полученной части каталога.
- Начальная глубина 1. Worker завершается при смене глубины, выходе из раздела,
  ошибке или исчерпании поиска; ответы прежнего экземпляра игнорируются.
- Справочник не получает Plan/setPlan, доступен независимо от настройки
  ограничения, не запускает производственный solver и не сохраняет изменения
  плана. Стили изолированы в `splitterSchemes.css`.
