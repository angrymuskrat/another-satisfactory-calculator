# Оставшиеся пункты игрового аудита

Пользователь запросил реализацию оставшихся F03/F04/F10/F11 после P2.
Основание — перечень остатка в задаче и gameplay-audit от 2026-09-06.

## Решения

- Стоимости компенсатора и спутников импортируются из закреплённых Docs
  с проверкой единичного строительного рецепта и всех материалов. Хранятся
  в дополнении p2-mechanics и применяются только к соответствующей версии каталога.
- Полный граф исследований, игровые категории и слоты плавильни требуют
  проверяемых assets той же сборки. Доступность не выводится из неполных Docs.
  При отсутствии экспорта сохраняются явные ограничения и отчёт о проверке.
- Клавиатура, фокус, семантика и объявления статусов проверяются на основных
  экранах и закрепляются браузерными тестами. Автотест дерева доступности
  не считается проверкой настоящим скринридером.
- Для трёх сценариев с игроками готовится воспроизводимый протокол и форма
  результатов. Наблюдения пользователей не выдумываются.
- Оптимизация частот, батареи, динамика труб и геометрия остаются вне этого запроса.

## Проверяемые этапы

- [x] Импорт и ведомость стоимости скважин; пример с несколькими спутниками.
- [x] Исследование assets: граф HUB/MAM, категории, слоты плавильни.
- [x] Исправления доступности и браузерные проверки.
- [x] Протокол сценариев с игроками и обновление статуса аудита.
- [x] Итоговые тесты, сборка и независимый обзор изменений.
