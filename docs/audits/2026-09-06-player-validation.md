# Проверка с игроками и скринридером

Статус: **подготовлено, с участниками не проведено**. Автотесты проекта
проверяют вычисления и взаимодействия, но не доказывают понятность интерфейса.
Этот документ не является отчётом о состоявшемся исследовании.

## Проведение

Использовать отдельный гостевой профиль браузера без пользовательских сохранений.
Запустить `pnpm dev`, открыть адрес из терминала. Зафиксировать commit/patch,
версию каталога, браузер, размер экрана, опыт участника и способ ввода.
Для одинаковых начальных условий ведущий может импортировать подготовленные
планы через «Импортировать JSON»: [первая фабрика](scenarios/01-first-factory.json),
[нефть](scenarios/02-oil.json), [расширение](scenarios/03-expansion.json).
Файлы прошли runtime-валидацию плана; решения контрольных примеров проверены
реальным решателем отдельно. При проверке самостоятельного ввода задания
сначала дать пустую попытку, а подготовленный файл использовать для повторения.
Приглашение участников и запись голоса/экрана выполняются отдельно с их согласием.

Рекомендуются хотя бы один начинающий и два опытных игрока. Это качественная
проверка, не статистическое исследование. Дать каждому три задания ниже;
не объяснять расположение кнопок до первой самостоятельной попытки. Записывать
время до результата, ошибки, подсказки ведущего и пересказ результата участником.
Если нужна помощь, отметить момент вмешательства; выполнение с подсказкой не
считать самостоятельным успехом.

## 1. Первая фабрика

Задание игроку: «Есть один обычный узел железа с буром Mk.2. Получите
7,5 усиленных железных пластин в минуту. Узнайте, что строить и как настроить
сборщики. Средний и пиковый расход энергии объясните своими словами».

Начальные данные: обычный новый план; стандартные рецепты, частоты 100%,
цель 7,5/мин в режиме заданного выпуска, лента Mk.3, утилизация выключена.
Проверка ведущего: два сборщика, 100% частота, 75% времени работы; группа
даёт 7,5/мин, средняя мощность сборщиков 22,5 МВт, пик 30 МВт.
Доля времени не должна восприниматься как настройка частоты 75%.
Попросить найти ведомость материалов и отметить один этап построенным,
перезагрузить страницу и проверить сохранение отметки.

## 2. Нефть и побочный продукт

Задание игроку: «Доступно 120 м³ нефти в минуту. Нужен пластик. Объясните,
почему без назначения тяжёлого нефтяного остатка выпуск ограничен, и создайте
работающий план с конечной отгрузкой остатка в соседнюю фабрику».

Начальные данные: один поток нефти 120/мин; включён только стандартный рецепт
пластика, одна цель «Пластик», режим максимума, частота 100%, утилизация выключена.
Сначала без отгрузки: стационарный положительный выпуск невозможен.
Затем добавить отгрузку тяжёлого нефтяного остатка с пределом 40 м³/мин.
Проверка ведущего: пластик 80/мин, нефть 120/мин, отгрузка остатка 40/мин,
четыре нефтеперерабатывающих завода; энергию внешней нефти нельзя назвать нулевой.
Игрок должен объяснить, что отгрузке нужен постоянный получатель: это не
бесконечное накопление в баке и не автоматически созданная вторая фабрика.

## 3. Расширение существующей фабрики

Задание игроку: «Один конструктор уже делает железные стержни. Железных слитков
теперь доступно 30/мин. Сравните сохранение фабрики и достройку; назовите,
сколько новых машин и материалов потребуется».

Начальные данные: единственный рецепт «Железный стержень», источник слитков
30/мин, одна цель стержней в режиме максимума, частота 100%, усилителей нет.
Существующая линия: один конструктор, 100%, доля работы 100%, выпуск закреплён.
Проверка ведущего: «Оставить» даёт 15/мин; «Достроить» — 30/мин с одним новым
конструктором. В новых материалах не должна повторно учитываться старая машина.
Попросить сохранить фабрику в мире и объяснить разницу источника и общей квоты.

## Отдельный проход скринридером

Проводится человеком с NVDA/Chrome или Narrator/Edge. Записать точные версии
и фактически услышанные фразы. Просмотр ARIA-дерева этого шага не заменяет.

1. Пройти пять разделов навигации; определить текущий раздел и заголовки.
2. Выбрать продукт поиском; проверить название, состояние выбора, закрытие
   Escape/кнопкой и возвращение фокуса к исходному полю.
3. Ввести недопустимое число; услышать ошибку и затем исправить его.
4. Запустить расчёт; услышать краткий статус, затем самостоятельно прочитать
   продукты, среднюю/пиковую мощность и этапы без повторного чтения всего экрана.
5. Пройти настройку источника, партии, линии, мира и формы входа только клавиатурой.
6. Открыть и отменить сброс; проверить удержание фокуса в диалоге и его возврат.
7. На 200% масштабе проверить доступность всех элементов без потери содержания.

## Форма результата

Заполнять по одному экземпляру на участника. До проведения ячейки пустые.

| Поле | Наблюдение |
| --- | --- |
| Дата, участник (псевдоним), опыт | |
| Сборка, браузер, экран, скринридер | |
| Сценарий 1: время, результат, подсказки | |
| Сценарий 2: время, результат, подсказки | |
| Сценарий 3: время, результат, подсказки | |
| Фактически произнесённые статусы / потеря фокуса | |
| Неправильно понятые показатели | |
| Ошибки и шаги воспроизведения | |
| Решение: исправить / повторно проверить / принято | |

Критерий закрытия: участник выполняет все сценарии, различает частоту и долю
работы, пик и среднюю мощность, конечную отгрузку и склад; нет блокирующих ошибок
клавиатуры или скринридера. После исправления обнаруженного препятствия повторить
соответствующий сценарий и связать отчёт с исправлением.
