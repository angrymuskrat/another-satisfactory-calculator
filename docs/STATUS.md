# Состояние проекта

Обновлено: 2026-09-06.

## Реализовано

- Архитектура и заданные частоты первой версии согласованы пользователем.
- React/Vite UI: планировщик, рецепты, технологии, профили; русский desktop/mobile,
  поиск, фильтры, иконки, таблицы этапов без Sankey.
- HiGHS в Web Worker: два режима, три политики выпуска, последовательные цели,
  ограничения источников/месторождений/транспорта/MW, фиксированные частоты,
  циклы, разрешённая утилизация с целым числом утилизаторов.
- Невыполнимый заказ сохраняется; достижимый выпуск рассчитывается отдельно.
- Независимая перепроверка баланса, лимитов и мощности по Plan/Catalog.
- Fastify/SQLite: аккаунты, scrypt, HttpOnly-сессии, CSRF, rate limiting,
  профили/планы с revision и изоляцией пользователей. Локальные черновики и JSON.
- Каталог из официального установленного Steam build 24656030: 276 рецептов,
  110 альтернативных, 152 предмета, 162 иконки; русские названия из ru.json.
  Исправлены 3 расхождения upstream и добавлены 6 рецептов; hash/provenance сохранены.
- Команды запуска и ограничения в README; AGENTS.md обновлён для текущей структуры.

## Оставшиеся ограничения

- Заголовки и состав групп рецептов пока тематические; точное меню игры не восстановлено.
  Docs не содержит mCategory/FGItemCategory. Порядок внутри групп соответствует
  mManufacturingMenuPriority. Доказательства в game-data/source/menu-evidence.json.
- Скважины с общим компенсатором давления не моделируются; азот — внешний поток.
- Автоподбор частот и Somersloops не входят в согласованную V1. Мощность средняя,
  standby/пуски не учтены; пиковая оценка вынесена отдельно.
- При timeout промежуточный недоказанный incumbent не показывается.
- Разные версии каталога не мигрируются автоматически: исходный профиль сохраняется,
  несовместимый импорт отклоняется с объяснением.

## Запуск и передача

- Рабочая ветка: codex/calculator-v1. Удалённый Git remote не настроен.
- Готовая сборка запущена на http://127.0.0.1:3002 (PORT=3002).
- Для разработки: node scripts/dev.mjs, порты 5173/3001; для готовой сборки pnpm start.
- База .data/users.sqlite и runtime-артефакты исключены из Git.
- Browser tests создают технические учётные записи ui-<timestamp>.
- Следующий содержательный шаг: получить category assets игры для точных групп;
  затем развивать следующие возможности по запросу пользователя.

## Особенности среды

- Node.js 24 доступен; pnpm поставляется в bundled runtime Codex, системного npm нет.
- Git под sandbox-пользователем требует разового -c safe.directory для рабочей папки.
  Глобальный Git config не менялся.
- Vitest работает с --configLoader runner. Vite/esbuild требует запуск вне sandbox
  из-за ACL родительских каталогов; установка и сборка одобрены automatic review.
